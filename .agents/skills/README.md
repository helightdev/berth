# Agent skills

Skills for coding agents that work with berth. Each skill is a folder with a
`SKILL.md` that starts with a YAML header (`name`, `description`) and then
has the instructions in Markdown.

| Skill | Use it to |
| --- | --- |
| [`install-berth`](install-berth/SKILL.md) | Install the berth client, a berth server, an Incus and Docker host, or Ubuntu on a server from a rescue system |

`.claude/skills` is a link to this folder, so Claude Code finds the same skills.
