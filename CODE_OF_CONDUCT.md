# Code of conduct

Be decent to each other. Argue about the code and the idea, and leave the
person out of it. Assume the other side means well until they show otherwise,
and say so plainly when something isn't working for you.

Harassment, insults and personal attacks aren't welcome here, in issues, pull
requests or anywhere else the project lives. The maintainer may edit or remove
such contributions and block accounts that keep at it.

If someone's behaviour in the project troubles you, report it through
**Report a vulnerability** under the repository's Security tab. That report is
private and reaches the maintainer.
