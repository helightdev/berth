berth sets up Ubuntu 26.04 amd64 machines for coding agents and manages them from your own computer. Each machine, a *host*, gets a desktop you can watch from the browser and the agents you choose. berth's terminal UI has a page per host for status, sign-ins, updates and secrets.

<Screen name="overview" alt="The overview of a host in berth: its connection, and tasks grouped under System, Access, Sync, Sign-In, Backup and Set-Up" />

## On each host

- XFCE on a persistent virtual display, reached in the browser through noVNC
- Claude Code, Codex and Pi, with T3 Code as a web front end for them
- Firefox, Chromium, Chrome, LibreOffice, image, PDF and OCR tools
- Development toolchains for Node, Python, Go, Rust, the JVM, .NET and more ([Tools](/docs/reference/tools))
- A desktop adapter for agents, as a command and as an MCP server ([box](/docs/reference/box))
- Tailscale, the Cockpit web console and unattended security updates
- An *operator* account for you and an *agent* account for the coding agents

A laptop also gets a physical XFCE login. Graphics run on the host's GPU or on the CPU ([Graphics](/docs/reference/graphics)). Optional software, such as the Unity CLI or nightly backups, comes as [plugins](/docs/extend/plugins).
